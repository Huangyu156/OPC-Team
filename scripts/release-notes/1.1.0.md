OPC-Team 1.1.0 桌面端更新

本次版本带来两项新能力：Claude 风格主题外观，以及智能助手工作区位置自定义。

- Claude 主题外观：新增「Claude」与「Claude 夜」两套内置主题，复刻 Claude 桌面端的暖色视觉语言——象牙白画布（浅色）/ 暖近黑画布（深色）、赤陶橙点缀色、暖色系发丝线与阴影，完整映射编辑器语法高亮与终端配色，可在 设置 → 外观 或左下角主题菜单中切换。
- 编辑衬线排版：Claude 外观下，欢迎页品牌语、页面/面板/分区标题与对话正文标题等阅读型文字自动采用衬线字体（仅拉丁字形；中文继续使用本地化无衬线字体，保证排版度量不变），界面控件与导航保持无衬线。
- 智能助手工作区位置自定义：新增 设置 → 数据与维护 → 智能助手存储 页面，可将智能助手工作区的保存位置从默认的产品主目录改到任意磁盘的任意目录（不再锁定 C 盘）；已有的助手保持原位置不变，新旧两个位置都会被识别。
- 存储位置双端可用：智能助手存储页面在桌面端与浏览器/Web 模式下均可用（新增 app server 的 workspace/assistantLocations 方法）。
- 兼容性：新的工作区根目录配置项按容错方式读取——旧版本忽略该字段，相对路径或空值自动回退默认位置；配置升级无需手动迁移。
