OPC-Team 1.0.7 桌面端更新

本次版本基于同步后的上游 1.0.6 代码，重点是移除桌面端自动更新能力，让这个仓库成为完全可控的自定义开发基线。

- 自动更新整体移除：桌面端不再注册 updater 插件，不再编译 `tauri-plugin-updater`，也不再内置更新检查、下载、安装与重启流程；设置页、标题栏角标、更新通知卡片与每日检查在启动时都会消失。
- 界面相应精简：应用设置中的「应用更新」分组、关于对话框的更新区块、左下角更新入口与对应文案全部下线；远端连接版本失效时，改为提供「打开发布页」按钮跳转到 GitHub Releases。
- 打包流程同步收敛：桌面打包不再生成 updater 制品，也不再需要 updater 公钥/私钥与 endpoint 环境变量；产物为 NSIS 安装包和自定义安装器。
- 版本元数据：桌面版本提升到 1.0.7，仓库内 release 清单与 Cargo workspace 版本保持一致。
- 兼容性：已持久化的配置项（如 `app.auto_update`）继续按容错方式读取，不会因为字段消失而丢弃用户配置。
